## 3. 公开表达与真实行为的张力案例

1. 「用完即走」vs 用户使用时长：张小龙 2016 年公开课提出「用完即走」，钛媒体《张小龙悖论》指出用户日均使用微信超 90 分钟（2016）；2021 年张小龙公开回应「不关注用户使用时长，和『用完即走』是两回事」，说明该张力持续存在。出处：钛媒体 https://www.tmtpost.com/2551436.html ；新浪科技 https://finance.sina.com.cn/tech/2021-01-19/doc-ikftssan8407105.shtml
2. 「克制、不打扰」vs 功能叠加与强推直播：微信 8.0 大更新叠加状态、直播、购物等功能（财新、钛媒体批评）；2020-11 微信在朋友圈大规模插入视频号直播引导，用户反弹「丑出天际」（荔枝网）。
3. 「善良」vs 封杀竞品：王小川称其「善良」的同时，微信接连封杀多闪、马桶MT、聊天宝（澎湃《善良的张小龙，不友善的微信》）。
4. 「去中心化」vs 小程序中心化：2016 年主张小程序「去中心化」，被钛媒体批评为「中心化巨型 I/O」；界面批评开放二维码入口是「亦步亦趋的妥协」。
5. 「现在不能做游戏」vs 一年后上线小游戏：GameRes 对照 2016-12-28 与 2017-12-28（https://www.gameres.com/789914.html）。
6. 「微信是工具、不急于赚钱」vs 商业化压力：张小龙长期拒绝加广告位，商业化部门多次要求加广告被拒（虎嗅 2026）；财新 2014 报道微信商业化慢、商务话语权集中于张小龙，被内外诟病「保守」。

## 4. 争议点清单

1. 「克制」是否被神化：极客公园、老道消息、胡泳等均质疑「克制」标签与造神；张小龙本人不认同「克制」说法。
2. 微信是否越来越臃肿：8.0 后功能清单持续膨胀（视频号、直播、状态、购物、小程序、小游戏、搜一搜、看一看等）。
3. 商业化过慢是「克制」还是「错失」：财新 2014 封面报道《微信学做生意》vs 2020 年后微信电商/直播的追赶式布局。
4. 小程序成败之争：开发者「被高估」「骗局」声音 vs 官方 DAU 叙事；去中心化与中心化之辩。
5. 视频号曲折：2020 朋友圈强推 → 演唱会路线 → 带货之争 → 缺运营铁军（证券时报）。
6. 封闭生态与监管：外链屏蔽墙（2021 工信部）、封杀社交竞品、2026 元宝事件。
7. 产品话语权与内部权力结构：财新《微信学做生意》「张小龙掌控产品话语权」；商业化部门与张小龙的持续张力（虎嗅 2026）。
8. 公开表达与真实行为的一致性（详见第 3 节张力案例）。
9. 公众批评的规模感：张小龙 2019 微信公开课自述「每天都有5亿人说我们做得不好，每天还有1亿人想教我怎么样做产品」（品玩，2019-01-08，https://www.pingwest.com/w/182292），说明公众批评是常态，其本人以自嘲方式回应。
