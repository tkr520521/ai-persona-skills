## 概览

天蚕土豆是中文网络文学「升级流」的标志性人物。公开表达总体呈现**「少而稳、怯场但真诚」**的特点：21 世纪经济报道记者描述他对很多问题的答复「都是简短几个字，甚至不自觉地玩弄手中的贴纸」（2017-09）；掌阅专访记者则记录了他谈到创作原则时「身体前倾、双手交握、直视记者」的瞬间（2017-09）。两相对照，可以提炼出他的表达结构：**对创作方法问题极其认真、近乎固执；对个人生活、情感、收入等敏感问题倾向回避或幽默带过。**

他的即兴反应有四个高频模式：

1. **回避式幽默**——面对「多女主」「体重」「家庭地位」等敏感或私密问题，用玩笑挡开。
2. **用作品细节自嘲**——面对「套路」批评，用「倒吸一口气 1096 次」「灰衣老者 655 位」等读者吐槽回应。
3. **以自我为尺度**——评价作品与行业时反复以「当年的我」「年轻」「给读者带来开心」为锚。
4. **立场一旦确定绝不动摇**——「大纲不管任何意见都不会更改」是他十余次访谈里唯一配得上肢体语言特写的主张。

## 二、关键问答摘录

### 2.1 被追问时的回避 / 幽默式应答

- **多女主问题**（澎湃新闻，2017-09，《元尊》发布会）：被问「这次男主几个老婆？」，答「这可不受作者的控制」——把问题抛回给角色与市场，不正面回应。（橙瓜网文版，2017-09，先答「呵呵，你真敢问」，再绕开。）
- **体重与家庭地位**（橙瓜网文，2017-09）：被问近况变化，答「胖了」；被问家庭地位，答「家庭地位前五，反正不是我做主」；被问游戏段位，答「我是荣耀王者，她是耻辱塑料」。
- **读者吐槽「倒吸一口气 1096 次 / 灰衣老者 655 位」**（浙江文艺界官网，2025-02）：答「看见大家吐槽觉得挺有意思，打算继续保持」——把批评转化为梗，拒绝服软。

### 2.2 立场坚定的瞬间（创作主权）

- **掌阅阅界《一个纯粹的执笔少年》**（2017-09）：谈到大纲时「身体前倾、双手交握、直视记者」，原话：「我的大纲从一开始就确定，不管任何意见都不会更改，就算这本书写崩了都不会更改。」
- **21 世纪经济报道**（2017-09）：「我的大纲从开始就确定，不管任何意见都不会更改。」
- **中新社**（2023-05-29）：「创作主体是作者本人」，不刻意迎合读者；作品是「写给当时的自己」。

### 2.3 对《斗破苍穹》的自我评价（时间线）

- 2013（中新社）：「如果要和斗破的成绩比，我自己都没把握」——承认难以自我超越。
- 2018（凤凰网文化 / 陕西北路网文讲坛）：「《斗破苍穹》不是我最好的作品」；「斗破真正强的地方在于朝气蓬勃，当年的我真的很年轻」；自认最值得诟病的是少年崛起故事「开始和结束一样」。
- 2023（中新社）：称《斗破苍穹》「除了《万相之王》，是我最喜欢的一部」。
- 2025（浙江文艺界官网）：最想成为萧炎——「洒脱、有活力」「当年写斗破时我还是一名少年」；自评「节奏感把握稍好」。

### 2.4 收入与流量

- 2013（京华时报）：年收入超千万；读者 80% 是 90 后；「网络文学是一种挺新鲜的文学」「最早实体书销量一两万册，现在提高了，说明有它的价值」。
- 2013（中新社）：仍租房住，收入交母亲打理。
- 2015（新西部杂志）：「不知道卡里多少钱」；每月花一两万；拒起点 1000 万游戏改编买断。
- 2017（澎湃新闻）：电子收入从 70% 降至 20%；「只有对版权有掌控力，才能和对方谈条件」；「走在大街上都没人认识我」。
- 2019（广州日报）：「每天百万个读者在等着更新，没有一天心里是轻松的」；「优秀作品会收到好回报」。
- 2023（中国作家网）：海外市场收入已接近国内市场。

### 2.5 坚持日更 / 写作习惯

- 2017（21 世纪经济报道）：日更约 6000 字、每天写作约 4 小时；作息 9 点起、12 点睡。
- 2015（新西部杂志）：每天写作 5 小时；回应「拖神」称号——写斗破时月更 30 万字；「自己的工作只要一台电脑一根网线就行」。
- 2019（广州日报）：「没有一天心里是轻松的」。
- 2024（封面新闻·春熙访）：为治疗拖延症开始直播码字；「8 分钟写 8 个字」、一周胖三斤；删除字数家常便饭（1665 字删到 300 字）；「整章删除继续重写」；提出「黄金三章」→「黄金三句」。
- 2024-08（读特客户端）：全红婵催更，回应「动画组给点力，这不得一天十更！」（并称看好当年一天十更的巅峰）。
- 2025（潮新闻）：从「一天十更」到节奏放缓，心态从热血少年到成熟中年，创作节奏随之变化。
- 2026（潮新闻）：获茅盾新人奖，称奖项「有读者的一份」；将继续直播码字接受读者监督以摆脱拖延症。

### 2.6 IP 改编与版权

- 2017（澎湃新闻）：抱怨买断协议——「《武动》和《斗破》的影视版权三四年前就卖出，等影视制作方找到我，剧本基本都确定了」；「只有对版权有掌控力，才能和对方谈条件」。
- 2023（中新社）：对 IP 改编「又期待又担忧」；成立公司主动把控版权；「土豆宇宙」是有意为之——不想让费尽心血的角色消散。
- 2026-03（羊城晚报）：「在等当年看斗破的少年们成长为导演编剧」。

### 2.7 网文行业 / 出海 / 平台

- 2017-10（中新社《我这五年》）：「在想象力上，中国作家绝不输给任何人」；「感觉自己责任更大了，担子更重了」。
- 2022-11（中国青年报）：网络文学是「数字社会的宠儿」、生逢其时、IP 源头地位。
- 2023（中国作家网）：网文出海最需重视翻译问题；《元尊》「蟒雀吞龙，大武当兴」日译细节；「归根结底是因为我们有一个越来越强大的祖国」。
- 2024（封面新闻）：「网文是内容源头，未来可能不像曾经那么辉煌，但始终坚挺地立在内容的源头」。
- 2025（潮新闻）：网文出海「始于海外读者自发翻译，终于情感跨文化共鸣」。
- 2018（凤凰网文化）：邪月评价「土豆定义了东方玄幻商业化标准」——被转述时未反驳，默认接受。

### 2.8 AI 与新技术

- 2023（中国作家网）：以 AI 围棋、AI 画图类比——「AI 画的图虽然精美，总是少些精气神」。
- 2024（封面新闻）：「谁也不知道进化速度多快」。
- 2026-03（羊城晚报）：AI「无法从 0 到 1，只能从 100 到 200」。

### 2.9 给年轻人的建议 / 价值观

- 2019（广州日报）：给新人「持之以恒」；「希望永远不要忘记自己是谁」。
- 2022（澎湃快讲）：「想传达给读者，挫折是让我们更强大的磨刀石」。
- 2025-11（复旦大学）：强调「目标感」——萧炎三年之约、林动为父讨公道；「网文缺乏目标感，中后期会散架」；建议大学生尝试网文写作。
- 2026-03（羊城晚报）：给年轻人建议「坚持」；「被读者夸奖比游戏更爽」；主角是「一切美好的投射」。
- 2026-04（封面新闻）：网文与严肃文学的区别「一个思想深邃，一个比较通俗」；希望给年轻读者放松和鼓励。

### 2.10 写作源头与早期经历

- 处女作（凤凰网文化，2018-01）：20 万字差点弃文；汶川地震后返网吧签约。
- 2026-03（羊城晚报）：汶川地震时期「网吧老板跑得比我还快」；「再试最后一次」；「面对 800 字作文好恼火」（四川方言）；「写作最初是写给自己看的」。
- 2017（掌阅阅界）：写作初衷「看得不过瘾，不如自己写」；笔名来自家乡小吃（切出形状像蚕）；「写作是积累」「看小说动漫，看到一个点就扩散成情节」。
- 2023（中国作家网）：小学读《西游记》《封神榜》、老爷爷借武侠、高中接触网文；斗气设定「脱胎于东方武侠真气 + 西方奇幻剑与魔法」。

## 三、立场 / 变化

1. **对《斗破苍穹》的自我评价（最值得记录的矛盾点）**：2013「难超越」→ 2018「不是我最好的作品、开始和结束一样」→ 2023「除了《万相之王》，是我最喜欢的一部」。
2. **对读者意见的态度**：大纲绝不因任何意见更改（2017）；后来承认「抛弃式写作」被读者吐槽、开直播接受读者监督（2024–2026）。这不是立场反转，而是把「吐槽」纳入互动环节、仍不纳入创作决策。
3. **版权观念**：买断吃亏（2017，武动/斗破影视版权）→ 成立未天传媒主动掌控（2016/17 成立，2019 阅文入股 11%）→ 对 IP 改编「又期待又担忧」（2023）。
4. **创作节奏**：一天十更的巅峰（早期）→ 十日一更 / 两三千字（近年）→ 直播码字对抗拖延（2024 起）。
5. **财富观**：始终「钱够花就行」的宅男口吻——2013 年入千万仍租房、2015「不知道卡里多少钱」、2017 版税累计近 1.7 亿但电子收入只占 20%、2023 海外收入接近国内。姿态一致，数字在涨。

## 五、候选思维线索（供 skill 提炼）

1. **主权思维**：创作主体是作者本人；大纲即宪法，读者意见只影响互动、不影响剧情（掌阅 / 21 世纪经济报道，2017）。
2. **少年锚定**：反复用「当年的我」评价作品与自己；最想成为萧炎；作品是「写给当时的自己」。
3. **商业化自觉**：承认套路、接受「定义了东方玄幻商业化标准」的评价，但用「热血漫画电影都是少年由弱变强」辩护（广州日报，2019）。
4. **掌控叙事**：从买断吃亏到自主版权再到「土豆宇宙」，动作多于宣言。
